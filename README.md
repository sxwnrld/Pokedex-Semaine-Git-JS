# Pokedex

## Description

Ce projet consiste à créer un Pokédex permettant de consulter les différents Pokémon grâce à l'API PokéAPI.

### Fonctionnalités

- Page d'accueil
- Liste des Pokémon
- Recherche par nom ou numéro
- Filtrage par type
- Système de favoris
- Affichage des informations des Pokémon
- Mode clair / sombre
## Technologies utilisées

- HTML5
- CSS3
- JavaScript
- PokéAPI
- Git / GitHub
